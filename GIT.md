# Cambios para la rama de Abraham

Esta revisión reemplaza los módulos anteriores por un solo proyecto Maven con `src/main/java` y `src/test/java`. Conserva el nombre de paquete `puzzle.abraham` y el artifactId `proyectoia`.

Revisar `git status`, ejecutar las tres demostraciones y las pruebas antes de hacer commit. No se cambia `.git`, no se crean commits ni se hace push automáticamente.

Los ZIP/bundle anteriores corresponden a versiones previas. Para compartir la versión actual usar `abraham-consola.zip` o los fuentes de esta carpeta.
