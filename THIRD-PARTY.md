# Biblioteca JADE incluida

El proyecto utiliza JADE sin modificar, publicado por TILAB / Telecom Italia, distribuido bajo GNU Lesser General Public License. Se incluye como biblioteca separada y reemplazable; no está incrustado dentro del código del equipo.

- Coordenadas Maven: `net.sf.ingenias:jade:4.3`.
- Identificación del runtime observada en consola: JADE 4.3.3, revisión 6726, 2014/12/09.
- Binario: `lib/jade-4.3.jar`.
- SHA-256 del binario: `5D0A30D1F102F60B94E5E7DBD09BE418EFC8855F4C58C71E593290106773D8FA`.
- Distribución oficial de fuentes correspondiente al runtime: `lib/JADE-src-4.3.3.zip` (contiene `jade/build.properties` con `version=4.3.3`, código fuente y licencia original).
- Texto de licencia: `lib/LICENSE-LGPL-2.1.txt`.
- [Origen del binario](https://repo.maven.apache.org/maven2/net/sf/ingenias/jade/4.3/jade-4.3.jar).
- [Origen oficial de las fuentes](https://jade.tilab.com/dl.php?file=JADE-src-4.3.3.zip).
- [Licencia GNU LGPL 2.1](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html).
- [Documentación del proyecto JADE](https://jade-project.gitlab.io/).

Los archivos Java del equipo y los scripts de compilación se entregan como fuente editable. Para utilizar otro binario JADE compatible, puede sustituir el archivo en `lib` y volver a compilar, o actualizar la dependencia Maven.
